# 화면 와이어프레임

> 저해상도(low-fidelity) 텍스트 와이어프레임. `doc/5-project-principle.md`의 6개 페이지(LoginPage, SignupPage, PromotionListPage, PromotionDetailPage, PromotionFormPage, ApplicationStatusPage)를 기준으로 한다. 데스크톱 레이아웃만 그리며, 반응형은 화면별로 한 줄만 언급한다. 디자인 시스템/색상/타이포그래피는 다루지 않는다.

---

## 1. LoginPage

```text
+--------------------------------------------------+
|  단체급식 프로모션                                  |
+--------------------------------------------------+
|                                                    |
|              [ 이메일 입력란        ]              |
|              [ 비밀번호 입력란      ]              |
|              [        로그인        ]              |
|                                                    |
|              회원가입 하러 가기 (링크)               |
|                                                    |
+--------------------------------------------------+
```

- 요소: 이메일 입력, 비밀번호 입력, 로그인 버튼, 회원가입 화면 이동 링크
- 로그인 실패 시: "로그인 실패" 안내 문구 노출

**모바일 (폭 축소, 좌우 여백만 줄어듦)**

```text
+----------------------+
| 단체급식 프로모션      |
+----------------------+
| [ 이메일       ]     |
| [ 비밀번호     ]     |
| [   로그인    ]     |
| 회원가입 하러 가기     |
+----------------------+
```

## 2. SignupPage

```text
+--------------------------------------------------+
|  단체급식 프로모션 - 회원가입                        |
+--------------------------------------------------+
|                                                    |
|         [ 이름 입력란            ]                 |
|         [ 이메일 입력란          ]                 |
|         [ 비밀번호 입력란        ]                 |
|                                                    |
|         역할 선택: ( ) 영양사   ( ) 취식자           |
|                                                    |
|         [       회원가입 완료       ]              |
|                                                    |
|         로그인 화면으로 돌아가기 (링크)               |
|                                                    |
+--------------------------------------------------+
```

- 요소: 이름/이메일/비밀번호 입력, 역할(영양사/취식자) 선택, 회원가입 버튼, 로그인 이동 링크
- 이메일 중복 시: "이미 사용 중인 이메일" 안내

**모바일 (폭 축소, 좌우 여백만 줄어듦)**

```text
+----------------------+
| 회원가입              |
+----------------------+
| [ 이름         ]     |
| [ 이메일       ]     |
| [ 비밀번호     ]     |
| ( )영양사 ( )취식자   |
| [  회원가입 완료  ]  |
| 로그인 화면으로       |
+----------------------+
```

## 3. PromotionListPage

```text
+--------------------------------------------------+
| Header: 로고 | 로그인 사용자 이름 | 로그아웃          |
+--------------------------------------------------+
|                                    [ 프로모션 등록 ] <- 영양사만
+--------------------------------------------------+
| +----------------------------------------------+ |
| | 제목: 여름 특별 급식 이벤트                     | |
| | 신청기간: 2026-08-01 ~ 2026-08-20               | |
| | 모집인원 30명 / 현재신청인원 12명                | |
| +----------------------------------------------+ |
| +----------------------------------------------+ |
| | 제목: 건강식단 체험단 모집                       | |
| | 신청기간: 2026-08-05 ~ 2026-08-15               | |
| | 모집인원 20명 / 현재신청인원 20명 (마감)          | |
| +----------------------------------------------+ |
| ...                                               |
+--------------------------------------------------+
```

- 요소: 헤더(사용자 이름, 로그아웃), 프로모션 카드 목록(제목/신청기간/모집인원/현재신청인원), 영양사 로그인 시 "프로모션 등록" 버튼
- 카드 클릭 시 PromotionDetailPage로 이동
- 빈 상태: "등록된 프로모션 없음"

**모바일 (헤더 축약, 카드 폭 전체 사용, 등록 버튼 헤더 아래로 이동)**

```text
+----------------------+
| ☰  로그인 사용자 이름  |
+----------------------+
| [ 프로모션 등록 ]<-영양사만
+----------------------+
| 여름 특별 급식 이벤트 |
| 신청 08-01~08-20     |
| 30명/12명            |
+----------------------+
| 건강식단 체험단 모집  |
| 신청 08-05~08-15     |
| 20명/20명 (마감)     |
+----------------------+
```

## 4. PromotionDetailPage

```text
+--------------------------------------------------+
| Header: 로고 | 로그인 사용자 이름 | 로그아웃          |
+--------------------------------------------------+
| < 목록으로                                        |
|                                                    |
| 제목: 여름 특별 급식 이벤트                          |
|                                                    |
| 내용:                                              |
| ------------------------------------------------- |
| (프로모션 설명 텍스트)                              |
| ------------------------------------------------- |
|                                                    |
| 신청기간: 2026-08-01 ~ 2026-08-20                  |
| 진행일:   2026-08-25                               |
| 모집인원: 30명   현재신청인원: 12명                  |
|                                                    |
|            [ 신청하기 ]  또는  [ 신청 취소 ]         |
|            (신청완료 상태이면 "신청 완료" 표시)       |
|                                                    |
|  영양사 로그인 & 본인 등록건일 경우:                  |
|            [ 수정 ]   [ 삭제 ]                     |
+--------------------------------------------------+
```

- 요소: 제목/내용/신청기간/진행일/모집인원/현재신청인원, 신청/신청취소 버튼(취식자), 수정/삭제 버튼(등록자 영양사)
- 신청 종료일 지남: 신청 버튼 비활성화
- 이미 신청함: 버튼 대신 "신청 완료" 표시, 취소 버튼 노출

**모바일 (버튼 전체 폭, 나머지 레이아웃 동일)**

```text
+----------------------+
| ☰  로그인 사용자 이름  |
+----------------------+
| < 목록으로            |
| 여름 특별 급식 이벤트  |
| (설명 텍스트)          |
| 신청 08-01~08-20     |
| 진행일 08-25          |
| 30명/12명             |
| [    신청하기    ]    |
+----------------------+
```

## 5. PromotionFormPage (등록/수정 공용)

```text
+--------------------------------------------------+
| Header: 로고 | 로그인 사용자 이름 | 로그아웃          |
+--------------------------------------------------+
|  프로모션 등록 / 수정                                |
|                                                    |
|  제목      [ 입력란                    ]            |
|  내용      [ 여러 줄 입력란             ]            |
|            [                          ]            |
|  신청 시작일 [ 날짜 선택 ]  신청 종료일 [ 날짜 선택 ]  |
|  진행일      [ 날짜 선택 ]                          |
|  모집인원    [ 숫자 입력란 ]                         |
|                                                    |
|            [ 등록/저장 ]   [ 취소 ]                 |
|  (수정 화면일 경우 하단에 [ 삭제 ] 버튼 추가)          |
+--------------------------------------------------+
```

- 요소: 제목/내용/신청 시작일/신청 종료일/진행일/모집인원 입력, 등록(또는 저장) 버튼, 취소 버튼, 수정 시 삭제 버튼
- 유효성 오류: 항목별 오류 문구(예: 진행일이 신청 종료일보다 이전인 경우 오류 안내)
- 정원 축소 제한 위반 시: "현재 신청 인원 미만으로 축소 불가" 안내
- 삭제 시(신청자 존재): 삭제하면 신청 기록도 함께 삭제됨을 안내하는 확인 문구 노출

**모바일 (데스크톱은 신청 시작일/종료일이 한 줄에 나란히, 모바일은 각각 한 줄씩 세로로 쌓임)**

```text
+----------------------+
| 프로모션 등록/수정     |
| 제목 [        ]      |
| 내용 [        ]      |
|      [        ]      |
| 신청시작 [ 날짜 ]     |
| 신청종료 [ 날짜 ]     |
| 진행일   [ 날짜 ]     |
| 모집인원 [ 숫자 ]     |
| [  등록/저장  ][취소] |
+----------------------+
```

## 6. ApplicationStatusPage

```text
+--------------------------------------------------+
| Header: 로고 | 로그인 사용자 이름 | 로그아웃          |
+--------------------------------------------------+
| < 목록으로                                        |
|                                                    |
| 제목: 여름 특별 급식 이벤트                          |
| 모집인원: 30명   현재신청인원: 12명                  |
|                                                    |
| 신청자 목록                                        |
| +----------------------------------------------+ |
| | 이름       | 신청일시              |            |
| +----------------------------------------------+ |
| | 홍길동     | 2026-08-02 10:20      |            |
| | 김영희     | 2026-08-03 09:05      |            |
| | ...                                            |
| +----------------------------------------------+ |
+--------------------------------------------------+
```

- 요소: 프로모션 제목/모집인원/현재신청인원, 신청자 목록 테이블(이름, 신청일시)
- 본인 등록 프로모션만 접근 가능(타인 프로모션 접근 시 권한 없음 처리)
- 빈 상태: "신청자 없음"

**모바일 (테이블 대신 신청자별 카드가 세로로 쌓임)**

```text
+----------------------+
| < 목록으로            |
| 여름 특별 급식 이벤트  |
| 30명/12명             |
| 신청자 목록            |
+----------------------+
| 홍길동                |
| 2026-08-02 10:20      |
+----------------------+
| 김영희                |
| 2026-08-03 09:05      |
+----------------------+
```
