# 주요 사용자 시나리오 다이어그램

`prompts/domain-definition.md` 8장(주요 사용자 시나리오) 내용을 mermaid 시퀀스 다이어그램으로 표현한다.

## 1. 회원가입 및 로그인

```mermaid
sequenceDiagram
    actor 사용자
    participant 서비스

    사용자->>서비스: 회원가입 화면 진입
    사용자->>서비스: 이름, 이메일, 비밀번호 입력
    사용자->>서비스: 영양사 또는 취식자 역할 선택
    사용자->>서비스: 회원가입 완료 요청
    서비스-->>사용자: 회원가입 완료
    사용자->>서비스: 이메일, 비밀번호로 로그인 요청
    서비스-->>사용자: 역할에 맞는 서비스 화면 진입
```

## 2. 영양사가 프로모션을 등록하는 경우

```mermaid
sequenceDiagram
    actor 영양사
    participant 서비스
    actor 취식자

    영양사->>서비스: 로그인
    영양사->>서비스: 프로모션 등록 화면 진입
    영양사->>서비스: 제목, 내용, 신청 기간, 진행일, 모집 인원 입력
    영양사->>서비스: 등록 요청
    서비스-->>영양사: 등록 완료
    서비스-->>취식자: 프로모션 노출
```

## 3. 취식자가 프로모션을 신청하는 경우

```mermaid
sequenceDiagram
    actor 취식자
    participant 서비스

    취식자->>서비스: 로그인
    취식자->>서비스: 프로모션 목록 확인
    취식자->>서비스: 프로모션 선택
    서비스-->>취식자: 상세 내용 표시
    취식자->>서비스: 신청 요청
    서비스-->>취식자: 로그인 사용자 정보로 신청 등록
    서비스-->>취식자: 신청 완료 상태 표시
```

## 4. 영양사가 신청 현황을 확인하는 경우

```mermaid
sequenceDiagram
    actor 영양사
    participant 서비스

    영양사->>서비스: 로그인
    영양사->>서비스: 자신이 등록한 프로모션 선택
    서비스-->>영양사: 현재 신청 인원 표시
    서비스-->>영양사: 신청자 목록 표시
```
