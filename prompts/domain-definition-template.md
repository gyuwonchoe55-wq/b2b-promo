# 단체급식 프로모션 신청 서비스 도메인 정의서

## 1. 문제 정의

- 점포 관리자인 영양사가 프로모션을 진행할 때 안내문을 직접 출력하여 게시하고 있다.
- 프로모션 참가 신청도 종이 신청서를 통해 수기로 받고 있어 신청자 취합과 관리가 번거롭다.
- 영양사가 현재 신청 인원과 신청자를 바로 확인하기 어렵다.
- 취식자도 진행 중인 프로모션 정보를 확인하고 신청하기 위해 오프라인 안내를 확인해야 한다.

## 2. 서비스 목표

영양사가 프로모션을 온라인으로 등록하고, 취식자가 프로모션을 확인하여 바로 참가 신청할 수 있는 간단한 서비스를 제공한다.

핵심 흐름은 다음과 같다.

**회원가입/로그인 → 영양사 프로모션 등록 → 취식자 프로모션 확인 및 신청 → 영양사 신청 현황 확인**

---

## 3. 주요 사용자

모든 사용자는 회원가입 및 로그인 후 서비스를 이용한다.

사용자는 **영양사**와 **취식자**로 구분한다.

### 영양사

프로모션을 운영하는 관리자이다.

- 회원가입 및 로그인
- 프로모션 등록
- 등록한 프로모션 수정/삭제
- 프로모션별 신청 인원 확인
- 신청자 목록 확인

### 취식자

프로모션에 참여하는 사용자이다.

- 회원가입 및 로그인
- 프로모션 목록 조회
- 프로모션 상세 조회
- 프로모션 참가 신청
- 자신의 신청 여부 확인

---

## 4. 주요 기능

### 회원가입 및 로그인

- 사용자는 이름, 이메일, 비밀번호를 입력하여 회원가입할 수 있다.
- 이메일은 중복 가입할 수 없다.
- 회원가입 시 영양사 또는 취식자 역할을 가진다.
- 가입한 이메일과 비밀번호로 로그인할 수 있다.
- 로그인한 사용자만 서비스 기능을 이용할 수 있다.
- 로그인한 사용자의 역할에 따라 이용 가능한 기능이 달라진다.

### 프로모션 관리

- 영양사만 프로모션을 등록할 수 있다.
- 프로모션 등록 시 제목, 내용, 신청 기간, 진행일, 모집 인원을 입력한다.
- 진행일은 신청 종료일과 같거나 이후여야 한다.
- 영양사는 자신이 등록한 프로모션을 수정하거나 삭제할 수 있다.
- 신청자가 있는 프로모션은 모집 인원을 현재 신청 인원 미만으로 수정할 수 없다.
- 신청자가 있는 프로모션을 삭제하면 해당 신청 기록도 함께 삭제된다.

### 프로모션 조회

- 취식자는 등록된 프로모션 목록을 확인할 수 있다.
- 프로모션을 선택하면 상세 정보를 확인할 수 있다.
- 모집 인원과 현재 신청 인원을 확인할 수 있다.

### 프로모션 신청

- 취식자는 신청 가능한 프로모션에 참가 신청할 수 있다.
- 로그인한 사용자 정보를 기준으로 신청자를 기록한다.
- 동일한 사용자는 동일 프로모션에 중복 신청할 수 없다.
- 모집 인원이 모두 차면 추가 신청할 수 없다.
- 신청 종료일이 지나면 신청 버튼이 비활성화되어 추가 신청할 수 없다.
- 취식자는 자신의 신청을 취소(삭제)할 수 있다.

### 신청 현황 관리

- 영양사는 자신이 등록한 프로모션의 신청 인원을 확인할 수 있다.
- 프로모션별 신청자 목록을 확인할 수 있다.

## 5. 핵심 도메인

### User

서비스를 사용하는 회원이다.

주요 정보:

- 사용자 ID
- 이름
- 이메일
- 역할

역할:

- `MANAGER`: 영양사
- `PARTICIPANT`: 취식자

---

### Promotion

영양사가 취식자를 대상으로 등록하는 프로모션이다.

주요 정보:

- 프로모션 ID
- 등록자 ID
- 제목
- 설명
- 신청 시작일
- 신청 종료일
- 프로모션 진행일
- 모집 인원

---

### Application

취식자가 특정 프로모션에 참가 신청한 기록이다.

주요 정보:

- 신청 ID
- 프로모션 ID
- 사용자 ID
- 신청 일시

---

## 6. 도메인 관계

```text
User (영양사)
   │
   │ 등록
   ▼
Promotion
   │
   │ 신청
   ▼
Application
   │
   │ 신청자
   ▼
User (취식자)
```

관계로 표현하면 다음과 같다.

```text
User 1 ─── N Promotion
        (영양사가 여러 프로모션 등록)

Promotion 1 ─── N Application
        (하나의 프로모션에 여러 신청 존재)

User 1 ─── N Application
        (한 취식자가 여러 프로모션 신청)
```

## 7. 주요 비즈니스 규칙

### 사용자

- 모든 사용자는 회원가입 및 로그인 후 서비스를 이용한다.
- 사용자는 영양사와 취식자 역할로 구분한다.
- 사용자 역할에 따라 사용할 수 있는 기능이 다르다.

### 프로모션

- 영양사만 프로모션을 등록할 수 있다.
- 영양사는 자신이 등록한 프로모션만 수정하거나 삭제할 수 있다.
- 프로모션에는 신청 기간과 모집 인원이 존재한다.
- 진행일은 신청 종료일과 같거나 이후여야 한다.
- 신청자가 있는 프로모션은 모집 인원을 현재 신청 인원 미만으로 수정할 수 없다.
- 프로모션을 삭제하면 해당 신청 기록도 함께 삭제된다.

### 신청

- 취식자만 프로모션에 참가 신청할 수 있다.
- 신청 기간 내에만 신청할 수 있다.
- 동일한 취식자는 동일 프로모션에 한 번만 신청할 수 있다.
- 모집 인원을 초과하여 신청할 수 없다.
- 모집 인원 초과 여부는 신청 시점에 서버에서 원자적으로 검증한다.
- 취식자는 자신의 신청을 취소할 수 있다.

## 8. 주요 사용자 시나리오

### 회원가입 및 로그인

1. 사용자가 회원가입 화면에 들어간다.
2. 이름, 이메일, 비밀번호를 입력한다.
3. 영양사 또는 취식자 역할을 선택한다.
4. 회원가입을 완료한다.
5. 이메일과 비밀번호를 입력하여 로그인한다.
6. 역할에 맞는 서비스 화면에 진입한다.

### 영양사가 프로모션을 등록하는 경우

1. 영양사가 로그인한다.
2. 프로모션 등록 화면에 들어간다.
3. 제목, 내용, 신청 기간, 진행일, 모집 인원을 입력한다.
4. 등록 버튼을 누른다.
5. 프로모션이 취식자에게 노출된다.

### 취식자가 프로모션을 신청하는 경우

1. 취식자가 로그인한다.
2. 프로모션 목록을 확인한다.
3. 원하는 프로모션을 선택한다.
4. 상세 내용을 확인한다.
5. 신청 버튼을 누른다.
6. 로그인한 사용자 정보로 신청이 등록된다.
7. 신청 완료 상태를 확인한다.

### 영양사가 신청 현황을 확인하는 경우

1. 영양사가 로그인한다.
2. 자신이 등록한 프로모션을 선택한다.
3. 현재 신청 인원을 확인한다.
4. 신청자 목록을 확인한다.

## 9. MVP 범위

이번 개발에서는 **종이로 진행되던 프로모션 안내 및 참가 신청을 온라인으로 전환하는 최소 기능**만 구현한다.

### 포함

- 회원가입
- 로그인/로그아웃
- 영양사/취식자 역할 구분
- 프로모션 등록
- 프로모션 수정/삭제
- 프로모션 목록 조회
- 프로모션 상세 조회
- 프로모션 참가 신청
- 참가 신청 취소
- 중복 신청 방지
- 모집 인원 제한
- 신청 인원 확인
- 신청자 목록 확인

### 제외

- 고객사 관리
- 점포 관리
- 복잡한 사용자 권한 관리
- 비밀번호 재설정
- 회원 탈퇴
- 추첨 및 당첨자 선정
- 쿠폰/리워드 지급
- 푸시 알림
- QR 체크인
- 댓글
- 만족도 조사
- 통계 및 분석

---

## 10. 서비스 핵심 정의

이 서비스는

**“영양사가 종이로 진행하던 프로모션 안내와 참가 신청 관리를 온라인으로 전환하는 서비스”**이다.

MVP의 핵심 도메인은 **User / Promotion / Application** 세 가지이며, 다음 흐름이 정상적으로 동작하는 것을 최우선으로 한다.

**회원가입·로그인 → 영양사가 프로모션 등록 → 취식자가 조회·신청 → 영양사가 신청 현황 확인**
